# La Preventiva HyS

Sitio estático personalizado para el negocio La Preventiva HyS.

- Enfoque principal: Higiene y Seguridad en el Trabajo.
- Servicio complementario: electricidad.
- Contacto: WhatsApp oficial enlazado desde la web.
- Base visual y de estructura: demo `demo-electricista`, adaptada a la identidad, oferta y mensajes de este lead.
- Fotografías: imágenes de obra y electricidad que William compartió para preparar la web; se cargan desde el almacenamiento público de medios.
- Implementación: HTML, CSS y JavaScript nativos en `index.html`, adaptable a móvil y escritorio.

No requiere dependencias ni proceso de compilación. El formulario se reemplazó por enlaces directos a WhatsApp para evitar simular un envío que no tiene backend.
